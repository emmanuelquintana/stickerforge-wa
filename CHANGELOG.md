# Changelog

## 0.4.0 development

- Added a Tauri 2 desktop application with bilingual Sticker Studio, Audio Studio, local history, settings and StickerForge pack files.
- Retained the Node WhatsApp bot and shared the multimedia engine across desktop and chat workflows.
- Added a private desktop control channel, in-app pairing QR and encrypted desktop session persistence on Windows.
- Added verification for the Node redistributable and in-app FFmpeg download. Disabled unisolated social platform extraction by default.
- Retained the v0.3.0 command-line launcher sources.
