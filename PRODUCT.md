# StickerForge Desktop

StickerForge processes images, GIFs, video and audio on the user's Windows computer. Its editor is available independently of WhatsApp. The optional private bot serves the linked account and explicitly authorized contacts.

The first desktop workflow is to import a file, choose a square composition and a time range, check the output, then export. Connection state, work status and storage are visible without giving the editor less room to work.
