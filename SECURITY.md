# Security

Report vulnerabilities through GitHub private vulnerability reporting when available. Keep WhatsApp QR codes, session files, message content and phone numbers out of reports.

The desktop app uses a local WebView and typed Tauri commands. Multimedia processing runs through the retained engine with argument arrays, a demuxer and protocol allowlist, input size checks and bounded workers. A private bot is limited to direct chats and explicitly authorized numbers. Its saved session is encrypted using AES-256-GCM, with the key protected under the current Windows account by DPAPI. The legacy standalone terminal bot retains its original on-disk session format.

Direct video downloads require HTTPS. Each request and redirect resolves the destination, rejects non-public IPv4 answers and pins the connection to the approved address while preserving TLS hostname verification. Desktop platform extractors are disabled because the app does not provide an effective network sandbox for yt-dlp. Use an eligible direct link or import a local file in Sticker Studio.

Baileys is an unofficial WhatsApp integration. WhatsApp may restrict or suspend accounts that use it. Use a secondary account. Field 26 support is experimental. The bot checks that it encoded the audio payload before relay. It cannot confirm audio playback on the recipient's device before sending.

No telemetry is configured. Installer signature, clean-install testing and actual WhatsApp client interoperability must be verified before a production release.
